# 资料整理指南

## 你需要提供什么

- **原始文件**：Markdown、文本、Word、PDF、截图或现有文件夹都可以，不需要先合并。
- **CAD 的后续整理范围**：第一版已选择接入“先读”的 9 篇，其余材料可按研究问题继续整理。
- **可选的学习目标**：例如理解论文公式、实现算法、准备研究。没有明确目标也可以先整理。

## 如何接入零散记录

1. 把文件放入项目根目录的 `sources/`，保留原文件。
2. 执行扫描，记录哪些文件新增或变化。
3. 由大模型识别主题、重复段落、缺失背景和来源，提出合并方式。
4. 将整理结果保存到 `docs/`；不确定的信息明确标出，保留原文件与文章 ID 的对应关系。
5. 重建索引，更新栏目和搜索。

::: tip 扫描与整理
第一版扫描工具支持任意文件的变化检测；它不自动提取 PDF / Word 正文，也不调用模型。正文提取和内容合并需要后续依据实际文件接入。
:::

## 新增文章

复制 `templates/` 中对应模板到 `docs/` 的栏目目录，设置唯一 ID、标题、类别和标签。执行 `pnpm index` 后，导航、栏目页与文章索引会自动更新。开发预览中修改普通正文会自动刷新；增加文章后需要重建索引。

## 更新旧文章

保留文章 ID 和已发布路径，记录新来源与更新日期。大模型修改后恢复为待复核状态。个人想法保存在独立的 `notes/` 中，通过文章 ID 关联，避免被重新生成的正文覆盖。

## 可用命令

```sh
pnpm dev      # 本地预览
pnpm scan     # 检测原文件变化
pnpm index    # 重建导航和内容索引
pnpm build    # 检查链接并构建网站
```
