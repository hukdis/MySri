## 一、先读懂原图：每条箭头表示什么

原图的主线是：给定策略求价值（第 2 章）→ 求最优价值（第 3 章）→ 有模型时做规划（第 4 章）或无模型时从采样学习（第 5、7 章）→ 用函数代替表格（第 8 章）→ 直接参数化策略（第 9 章）→ 联合学习策略与价值（第 10 章）。第 6 章的随机逼近是理解增量式 TD 更新的数学桥梁。

| --------------- | ------------------------------ | ----------------------------- |
| 第 2 章 → 第 3 章   | 从固定策略的期望方程，改为对动作取最大值的最优性方程     | Bellman 方程本身是关系式，不等于具体学习算法    |

## 二、统一记号与判断维度

设 $S_t,A_t,R_{t+1},S_{t+1}$ 分别为时刻 $t$ 的状态、动作、下一步奖励和下一状态，$\gamma\in[0,1)$ 为折扣因子，$\pi(a\mid s)$ 为策略，$p(s',r\mid s,a)$ 为环境模型。回报为 $G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1}$；终止后的价值取 $0$。$v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]$，$q_\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a]$。$\alpha$ 是价值学习率，$\beta$ 是策略学习率。

读任何算法，先问四个问题：**是否知道模型？用完整回报还是自举目标？学习价值还是直接学习策略？数据策略与目标策略是否相同？** 这四个维度相互独立。例如 Q-learning 是无模型、TD 自举、价值型、离策略；DQN 仍属于这一类，但加入非线性函数近似。

## 三、基础工具：第 2—3 章

### 第 2 章：Bellman 方程——固定策略的价值评估

**解决什么问题。** 给定策略 $\pi$ 和环境模型，求“继续执行该策略”时每个状态或状态—动作对的期望回报。它是后续策略评估、TD、Critic 的共同起点。

**核心表达式。**

$$
v_\pi(s)=\sum_a\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)[r+\gamma v_\pi(s')],
\qquad
q_\pi(s,a)=\sum_{s',r}p(s',r\mid s,a)\left[r+\gamma\sum_{a'}\pi(a'\mid s')q_\pi(s',a')\right].
$$

矩阵形式是 $\boldsymbol v_\pi=\boldsymbol r_\pi+\gamma P_\pi\boldsymbol v_\pi$；在条件成立时可直接解得 $\boldsymbol v_\pi=(I-\gamma P_\pi)^{-1}\boldsymbol r_\pi$，或迭代 $v_{k+1}=T_\pi v_k$。

**区别与联系。** 第 2 章的 $T_\pi$ 对动作按给定策略加权；第 3 章的 $T_*$ 对动作取最大值。它求的是**某个策略的价值**，不自动产生最优策略。MC 通过完整采样回报估计同一个 $v_\pi/q_\pi$；TD 用一次转移近似其 Bellman 方程。

### 第 3 章：Bellman 最优性方程——把评估变为控制

**解决什么问题。** 第 2 章回答“给定策略 $\pi$，它有多好”；第 3 章进一步回答“从某个状态出发，能做到多好，以及该选什么动作”。定义 $v_*(s)=\max_\pi v_\pi(s)$；在有限折扣 MDP 中，存在对所有状态同时最优的确定性平稳策略，但最优策略未必唯一。

先写出**单步展望**：假设已经知道下一状态的最优价值 $v_*(s')$，那么在当前状态尝试动作 $a$ 的价值为 $\sum_{s',r}p(s',r\mid s,a)[r+\gamma v_*(s')]$。既然当前可以选择动作，就应对这个量取最大值，于是得到 Bellman 最优性方程：

$$
v_*(s)=\max_a\sum_{s',r}p(s',r\mid s,a)[r+\gamma v_*(s')],
\qquad
q_*(s,a)=\sum_{s',r}p(s',r\mid s,a)[r+\gamma\max_{a'}q_*(s',a')].
$$

### 第 3 章最重要的三个结论

1. **固定策略评估与最优控制的区别在一个算子。** $T_\pi v$ 对动作按 $\pi(a\mid s)$ 求平均，回答“照当前策略行动会怎样”；$T_*v$ 对动作取最大值，回答“现在选最好动作会怎样”。两者都先计算一步奖励加折扣后的价值，但所回答的问题不同。
2. **最优价值是最优性算子的不动点。** 写作 $v_*=T_*v_*$。在有限状态、有限动作、$0\le\gamma<1$ 的折扣设定下，$\|T_*u-T_*v\|_\infty\le\gamma\|u-v\|_\infty$。直观地说，下一步价值估计中的最大误差，经一次备份后至多剩下 $\gamma$ 倍；因此反复应用 $T_*$ 会逼近唯一的 $v_*$。这就是 VI 的依据，而不是“取最大值就自然收敛”。
3. **知道最优价值才能可靠地提取最优策略。** $\pi_*(s)\in\arg\max_a\sum_{s',r}p(s',r\mid s,a)[r+\gamma v_*(s')]$；若已有 $q_*$，则简化为 $\pi_*(s)\in\arg\max_a q_*(s,a)$。多个动作并列最优时可任选其一，也可在最优动作间随机化。

**它与算法的关系。** Bellman 最优性方程是**待求目标**，不是求解步骤。第 4 章 VI 直接迭代其最优性算子；PI 从任意策略出发，反复做固定策略评估与贪心改进；第 7 章 Q-learning 在未知模型时用采样近似动作价值最优性方程。

## 四、有模型规划：第 4 章

| 算法          | 解决的问题与核心表达式                                                                                                             | 与其他算法的区别、联系                                                     |
| ----------- | ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **价值迭代 VI** | 直接逼近 $v_*$：$v_{k+1}(s)=\max_a\sum_{s',r}p(s',r\mid s,a)[r+\gamma v_k(s')]$；收敛后贪心取策略。                                    | 每轮做一次最优性备份，不显式完成某个固定策略的精确评估；与 Q-learning 追逐同一最优性方程，但 VI 对模型求期望。 |
| **策略迭代 PI** | 交替做评估 $v_{\pi_k}=T_{\pi_k}v_{\pi_k}$ 与改进 $\pi_{k+1}(s)\in\arg\max_a\sum_{s',r}p(s',r\mid s,a)[r+\gamma v_{\pi_k}(s')]$。 | 每轮先充分评估当前策略，再贪心改进；比 VI 的单次备份更明确地分成两步。                           |
| **截断策略迭代**  | 只做 $m$ 次评估：$v\leftarrow T_{\pi_k}^{m}v$，再贪心改进。                                                                          | 位于 VI 与充分评估的 PI 之间，计算量与评估精度可权衡；是理解“广义策略迭代”的例子。                  |

### VI 与 PI：核心区别

两者都假设能利用模型 $p(s',r\mid s,a)$ 计算一步期望，最终都想获得最优策略。**差别不是“一个有策略、一个没有策略”**：VI 在每轮更新中也隐含了一个对当前价值贪心的策略；差别在于**是否先把某个固定策略评估充分，再改进它**。

| 观察点         | 价值迭代 VI                   | 策略迭代 PI                                               |
| ----------- | ------------------------- | ----------------------------------------------------- |
| 维护的主要对象     | 价值估计 $v_k$；可临时或最后提取贪心策略   | 显式维护策略 $\pi_k$ 及其价值 $v_{\pi_k}$                       |
| 一轮做什么       | 对每个状态做一次 $v_{k+1}=T_*v_k$ | 先求 $v_{\pi_k}=T_{\pi_k}v_{\pi_k}$，再令 $\pi_{k+1}$ 对它贪心 |
| 是否评估当前策略到收敛 | 不要求                       | 标准 PI 要求充分评估；可解线性方程或迭代至所需精度                           |
| 一轮的典型计算量    | 较小：一次遍历状态和动作、计算最优性备份      | 较大：评估可能需解方程或多次遍历，再做改进                                 |
| 轮数与总成本      | 可能需要较多次备份                 | 策略改进轮数可能较少，但每轮更贵；谁总体更快取决于问题与实现                        |
| 停止及输出       | 价值变化足够小后，从近似价值中提取贪心策略     | 改进后策略不再改变时，当前策略已最优（标准有限折扣情形）                          |

用两行更新式记住差别：

$$
\underbrace{v_{k+1}=T_*v_k}_{\text{VI：每轮直接朝最优价值备份}},
\qquad
\underbrace{v_{\pi_k}=T_{\pi_k}v_{\pi_k}\;\longrightarrow\;
\pi_{k+1}=\operatorname{Greedy}(v_{\pi_k})}_{\text{PI：先评估当前策略，再改进}}.
$$

**一个能看出差别的小例子。** 设折扣 $\gamma=0.9$。在状态 $s_1$ 可选“停留”，每步得 $0.5$ 并回到 $s_1$；或选“前往 $s_2$”，当步得 $0$。在 $s_2$ 唯一动作给 $10$ 奖励后终止。最优选择是“前往”：$v_*(s_2)=10$、$v_*(s_1)=0+0.9\times10=9$；一直停留只有 $0.5/(1-0.9)=5$。

- **VI** 从 $v_0(s_1)=v_0(s_2)=0$ 开始：第一轮 $v_1(s_1)=\max(0.5,0)=0.5$、$v_1(s_2)=10$；第二轮 $v_2(s_1)=\max(0.5+0.9\times0.5,0.9\times10)=9$。它没有先精确算出“总是停留”的价值 $5$。
- **PI** 若初始策略在 $s_1$ 选择“停留”，先评估出 $v_{\pi_0}(s_1)=5$、$v_{\pi_0}(s_2)=10$；改进时比较“停留”的 $0.5+0.9\times5=5$ 与“前往”的 $0.9\times10=9$，于是改为“前往”，再评估得 $9$。

**它们怎样连接。** 截断策略迭代只做若干次 $T_{\pi}$ 评估再改进，介于充分评估的 PI 与频繁改进的 VI 之间。**广义策略迭代 GPI** 指评估与改进交替推进的框架，不是另一个单独算法。VI、PI、MC 控制、Sarsa 与 Actor–Critic 都可从这一角度理解，只是评估所用的信息及交替频率不同。

## 五、无模型、基于完整回报：第 5 章 Monte Carlo

MC 用真实轨迹回报代替模型期望。**共同核心**是 $q_\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a]$，估计更新可写为

$
Q(s,a)\leftarrow Q(s,a)+\alpha\,[G_t-Q(s,a)].
$

若对某个 $(s,a)$ 使用第 $n$ 个独立回报并取 $\alpha=1/n$，就是样本均值递推；使用常数步长则更重视近期样本。

| 算法或环节                       | 解决什么问题                        | 关键做法与区别                                                         |
| --------------------------- | ----------------------------- | --------------------------------------------------------------- |
| **MC Basic**                | 展示不知道转移模型时如何估计 $q_\pi$ 并改进策略。 | 对从选定状态—动作出发的完整回合求平均回报，再按 $\arg\max_a Q(s,a)$ 改进；对轨迹内其他可用访问利用不足。 |
| **首次访问 / 每次访问 MC**          | 充分利用同一回合中出现的状态—动作对。           | 首次访问只用该回合中第一次出现的 $(s,a)$ 的回报；每次访问使用每一次出现。两者都用完整回报，并非 TD。        |
| **MC Exploring Starts**     | 让不同状态—动作对都有被估计的机会，同时逐回合改进。    | 要求起始 $(s,a)$ 可被充分探索；实践中常难以控制起始状态。可采用首次访问回报平均。                   |
| **MC $\varepsilon$-Greedy** | 用持续的动作探索替代难以实现的探索性起点假设。 | 原稿此行概率公式及比较说明不完整，待补齐。 |

MC 与第 4 章均可做评估—改进，但 MC **不需模型、需完整回合、无自举**；第 7 章 TD **一步后即可更新、有自举**。MC $\varepsilon$-greedy 在固定 $\varepsilon>0$ 时保持探索，目标是相应的软策略控制；不能把固定探索率下的行为策略直接说成完全贪心的最优策略。

## 六、数学桥梁：第 6 章随机逼近

这章主要给第 7 章提供增量更新的理论语言，不是另一套独立 RL 控制任务。

| 方法                     | 解决的问题              | 核心表达式与关联                                                                                                                                                  |
| ---------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Robbins–Monro 随机逼近** | 只能得到含噪声观测时求方程根或期望。 | 若希望解 $h(x)=0$，且 $H(x,\xi)$ 是 $h(x)$ 的随机估计，则 $x_{t+1}=x_t-\alpha_tH(x_t,\xi_t)$（符号取决于根函数定义）。均值估计是 $m_{t+1}=m_t+\alpha_t(X_t-m_t)$。TD 误差可看作含噪声的 Bellman 残差。 |
| **SGD**                | 目标是期望损失，却只能访问随机样本。 | $w_{t+1}=w_t-\alpha_t\nabla_w\ell(w_t;\xi_t)$；第 8 章价值近似和第 9 章策略梯度都借用随机梯度思想。                                                                               |
| **BGD / MBGD / SGD**   | 选择每次参数更新使用多少样本。    | 全批量用全部数据，小批量用一组样本，单样本 SGD 用一个样本；主要差别是每步计算量与梯度噪声。                                                                                                          |

经典收敛讨论常要求步长满足 $\sum_t\alpha_t=\infty$、$\sum_t\alpha_t^2<\infty$，并另需噪声、访问频率等条件；这两条本身不足以保证任意 RL 算法收敛。

## 七、无模型、基于自举：第 7 章 TD 学习

把 $G_t$ 换成使用当前价值估计构造的目标，是 TD 与 MC 的核心分界。**自举**意为更新目标中包含当前估计值。课件讲授如下算法：

| 算法                 | 解决的问题及核心更新                                                                                                                                                      | 区别与联系                                                             |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| **TD(0) 状态价值评估**   | 一步转移后更新固定策略的状态价值：$\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)$，$V(S_t)\leftarrow V(S_t)+\alpha\delta_t$。                                                          | 目标仍是 $v_\pi$；比 MC 更新更及时，但目标含估计偏差。                                 |
| **Sarsa**          | 在线、同策略地学习动作价值并控制：$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)]$。                                                        | 下一动作 $A_{t+1}$ 按当前行为策略实际采样，故会把探索动作的后果计入学习目标。                      |
| **Expected Sarsa** | 降低下一动作随机采样造成的目标方差：$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma\sum_{a'}\pi(a'\mid S_{t+1})Q(S_{t+1},a')-Q(S_t,A_t)]$。                                 | 与 Sarsa 估计同类策略价值，但用策略下的动作期望代替一次采样；若下一动作取纯贪心，其目标与 Q-learning 形式相同。 |
| **$n$ 步 Sarsa**    | 在一步 TD 和整回合 MC 间调节自举程度：$G_{t:t+n}=\sum_{k=1}^{n}\gamma^{k-1}R_{t+k}+\gamma^nQ(S_{t+n},A_{t+n})$，$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[G_{t:t+n}-Q(S_t,A_t)]$。 | $n=1$ 为 Sarsa；若 $n$ 延伸到回合终止，则尾部自举项消失，成为 MC 式回报。                   |
| **Q-learning**     | 从探索性行为数据学习最优动作价值：$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)]$。                                                     | 行为策略可含探索，而目标按贪心动作取最大值，属于离策略；它是第 3 章最优性方程的采样式近似。                   |

**统一模板**：$Q\leftarrow Q+\alpha(\text{目标}-Q)$。差别集中在“目标”如何构造：MC 用完整 $G_t$；Sarsa 用实际下一动作；Expected Sarsa 用下一动作分布的期望；Q-learning 用最大动作价值。这里的“同策略/离策略”说的是**行为数据与更新目标对应的策略**是否一致，不等同于是否使用经验回放。

## 八、从表格到泛化：第 8 章价值函数近似

当状态空间大或连续时，无法给每个状态或状态—动作对单独存一项。以参数 $w$ 定义 $\hat v(s;w)$ 或 $\hat q(s,a;w)$，使不同状态共享参数。课件从曲线拟合进入线性/非线性近似，再讨论 MC、TD、Sarsa、Q-learning 和 DQN。

| 方法                        | 解决的问题与核心表达式                                                                                                                   | 与前面方法的区别、联系                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **状态价值近似（MC 目标）**         | 最小化样本回报拟合误差，例如 $L(w)=\tfrac12(G_t-\hat v(S_t;w))^2$；$w\leftarrow w+\alpha[G_t-\hat v(S_t;w)]\nabla_w\hat v(S_t;w)$。           | 把第 5 章完整回报作为监督目标；目标不含当前 $w$。                                       |
| **状态价值近似（TD 目标）**         | 使用一步目标 $R_{t+1}+\gamma\hat v(S_{t+1};w)$：$w\leftarrow w+\alpha\delta_t\nabla_w\hat v(S_t;w)$。                                 | 是半梯度更新：求梯度时把目标视为常量；与普通固定标签的监督学习不同。                                 |
| **半梯度 Sarsa**             | $\delta_t=R_{t+1}+\gamma\hat q(S_{t+1},A_{t+1};w)-\hat q(S_t,A_t;w)$，$w\leftarrow w+\alpha\delta_t\nabla_w\hat q(S_t,A_t;w)$。 | 把第 7 章 Sarsa 表格项替换为共享参数的函数；仍由实际下一动作定义同策略目标。                        |
| **半梯度 Q-learning**        | $\delta_t=R_{t+1}+\gamma\max_{a'}\hat q(S_{t+1},a';w)-\hat q(S_t,A_t;w)$，按 $\delta_t\nabla_w\hat q(S_t,A_t;w)$ 更新。            | 把 Q-learning 与函数近似结合；离策略、自举、函数近似同时出现时，稳定性不能由表格 Q-learning 的结论直接保证。 |
| **DQN / Deep Q-learning** | 用神经网络近似 $Q$，冻结目标网络 $w^-$ 构造 $y_i=r_i+\gamma(1-d_i)\max_{a'}Q(s'_i,a';w^-)$，最小化 $L(w)=\frac1{2B}\sum_i[y_i-Q(s_i,a_i;w)]^2$。   | 延续 Q-learning 的贪心目标；目标网络减缓目标漂移，经验回放打散连续样本的相关性并复用数据。$d_i$ 表示终止。     |

注意：课件将 DQN 的训练写为带目标网络的平方 TD 误差，并讨论回放缓冲区的均匀抽样。严格说，单样本平方 TD 误差的期望与“先对转移取条件期望、再平方”的 Bellman 残差目标并不完全相同；这里按课件的实际训练式表述。课件中的网络接口可显式输入 $(s,a)$；常见 DQN 实现也可输入 $s$、输出各离散动作的 $Q$ 值，两种接口服务于同一贪心动作选择。

## 九、直接优化策略：第 9 章策略函数近似

**解决什么问题。**<u> 用 $\pi_\theta(a\mid s)$ 直接表示可微随机策略，优化期望回报，而不必先求出所有动作的最优 $Q$ 再贪心选动作。</u>课件比较以状态价值或平均奖励定义的策略性能指标，并推导策略梯度。

**策略梯度的核心式**可写为（$d_\pi$ 的具体归一化方式依性能指标而定）

$$
\nabla_\theta J(\theta)\propto
\mathbb E_{S\sim d_\pi,\,A\sim\pi_\theta}
\bigl[\nabla_\theta\log\pi_\theta(A\mid S)\,q_{\pi_\theta}(S,A)\bigr].
$$

**REINFORCE** 用完整回报 $G_t$ 代替未知的 $q_\pi$，逐回合进行 $\theta\leftarrow\theta+\beta\,G_t\nabla_\theta\log\pi_\theta(A_t\mid S_t)$。它与第 5 章 MC 的联系是都使用完整轨迹回报；区别是 MC 控制先估计表格 $Q$ 再贪心改进，REINFORCE 直接更新策略参数。它与第 10 章 Actor–Critic 的主要差别是后者引入通过 TD 等方法训练的 Critic 来估计 $q$ 或优势，通常可以更早更新，但引入估计偏差。

## 十、价值与策略联动：第 10 章 Actor–Critic

Actor 是策略 $\pi_\theta$，Critic 是 $\hat v_w$ 或 $\hat q_w$。**Critic 并不自动等于 DQN**：它评估 Actor 当前策略所需的价值，具体估计方法随算法而变。

| 课件算法                     | 解决的问题与核心表达式                                                                                                                                                                                                                                                 | 与其他算法的区别、联系                                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **QAC（最简 Actor–Critic）** | 用 Sarsa 式 Critic 估计 $q_\pi$：$\delta_t^q=R_{t+1}+\gamma\hat q_w(S_{t+1},A_{t+1})-\hat q_w(S_t,A_t)$，$w\leftarrow w+\alpha\delta_t^q\nabla_w\hat q_w(S_t,A_t)$；Actor：$\theta\leftarrow\theta+\beta\hat q_w(S_t,A_t)\nabla_\theta\log\pi_\theta(A_t\mid S_t)$。 | 课件中的基础同策略实例；与 REINFORCE 相比，回报估计来自 TD Critic 而非完整回合。                                                  |
| **A2C（优势 Actor–Critic）** | 以 $A_\pi(s,a)=q_\pi(s,a)-v_\pi(s)$ 衡量“该动作比状态平均水平好多少”；Actor 用 $\theta\leftarrow\theta+\beta\hat A_t\nabla_\theta\log\pi_\theta(A_t\mid S_t)$。一步状态价值 Critic 常用 $\hat A_t\approx R_{t+1}+\gamma\hat v_w(S_{t+1})-\hat v_w(S_t)$。                               | 给 QAC 的策略梯度加入状态基线以降低方差；$\mathbb E_{a\sim\pi}[\nabla\log\pi(a\mid s)b(s)]=0$，因此理想期望梯度不变。              |
| **离策略 Actor–Critic**     | 用行为策略 $b$ 的数据更新目标策略 $\pi_\theta$。基本重要性权重 $\rho_t=\pi_\theta(A_t\mid S_t)/b(A_t\mid S_t)$；一种加权梯度形式是 $\rho_t\hat q(S_t,A_t)\nabla_\theta\log\pi_\theta(A_t\mid S_t)$，同时 Critic 需对应的离策略估计。                                                                     | 与同策略 QAC/A2C 不同，可复用其他策略数据；重要性采样要求目标策略的动作在行为策略下有支持，且权重会增加方差。完整的离策略策略梯度还涉及状态分布或所选目标的定义，不能只凭动作权重一概声称无偏。 |
| **DPG（确定性策略梯度）** | 连续动作下直接学习 $a=\mu_\theta(s)$；原稿公式整理为下方独立公式。 | 原稿此行比较说明不完整，待补齐。 |

$
\nabla_\theta J\propto\mathbb E_{S\sim d}\bigl[\nabla_\theta\mu_\theta(S)\,\left.\nabla_a q^{\mu}(S,a)\right\vert_{a=\mu_\theta(S)}\bigr]
$

> 排版说明：上式由原稿 DPG 行被表格分隔符拆开的公式拼接整理；公式正确性仍待对照课件人工核对。

## 十一、把容易混淆的算法放在一起

| 对比                                  | 一句话分界                                             | 同一条主线                      |
| ----------------------------------- | ------------------------------------------------- | -------------------------- |
| VI / Q-learning                     | 都逼近 Bellman 最优性方程；VI 用模型求完整期望，Q-learning 从一次转移采样。 | 第 3 章最优性方程 → 第 4 章 / 第 7 章 |
| PI / MC 控制                          | 都交替评估、改进；PI 通过模型评估，MC 通过完整轨迹回报评估。                 | 广义策略迭代                     |
| MC / TD(0)                          | MC 用完整 $G_t$；TD(0) 用 $R_{t+1}+\gamma V(S_{t+1})$。 | 都在估计固定策略价值                 |
| Sarsa / Expected Sarsa / Q-learning | 下一步目标分别用实际抽样动作、策略期望、贪心最大值。                        | 都是动作价值的 TD 控制              |
| 表格 Q-learning / DQN                 | 目标结构相近；DQN 用神经网络、目标网络与回放。                         | 第 7 章 → 第 8 章              |
| REINFORCE / QAC / A2C               | 完整回报、TD 估计的 $Q$、减去基线的优势，依次替换策略梯度中的权重。             | 第 9 章 → 第 10 章             |
| Q-learning / DPG                    | 前者对离散候选动作取最大值，后者让可微 Actor 输出动作并沿 Critic 的动作梯度改进。  | 价值控制 → 直接策略优化              |

## 十二、建议的学习顺序与检查点

1. **方程先于算法**：能从回报递推推出 $v_\pi=T_\pi v_\pi$，再解释为何最优性方程出现 $\max_a$。
2. **先判断模型是否已知**：已知模型看 VI/PI；未知模型看 MC/TD。
3. **只改“目标”比较 MC、Sarsa、Expected Sarsa、Q-learning**：写下各自的 $\text{target}-Q$，再判断是否自举、是否同策略。
4. **把表格替换为共享参数**：理解半梯度为何冻结目标，再看 DQN 为什么需要目标网络及回放。
5. **把决策变量改为策略参数**：先掌握 REINFORCE 的对数导数形式，再看 QAC 的 Critic、A2C 的基线、离策略修正和 DPG 的动作梯度。
