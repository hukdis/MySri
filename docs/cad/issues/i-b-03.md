# 受限视角下隐藏几何仍易恢复不全，在线采集的位姿与成本条件尚待验证

> I-B-03 · 研究问题 · [CAD重建](/cad/tasks/reconstruction)

## 实际场景与失败条件

**场景**：只能从部分可达位置拍零件，视图预算有限且相机姿态或canonical anchor不完全可靠；希望生成可验证的CAD，而不是为不可见空腔猜一个确定结构。

**失败条件**：VGGT-CAD仍难处理细管和完全封闭空腔；CADForge在极端侧后视角可能恢复不全。SightCAD已经处理遮挡并做真实图，但从完整校准候选图像集选top-K，仍假设已知相机/距离/锚点。它与只允许逐次采集K张、未采图不可见的协议不同。

**后果**：看不见的孔或空腔可能被错误补全；把候选子集大小当实际采集成本会高估部署收益。增加外视角也无法保证辨认完全封闭内部结构，应报告不确定性或请求额外信息。

## 已有方案与剩余边界

### Yu26b

[VGGT-CAD](/cad/papers/yu26b)

**已经解决**：几何先验、相机编码与多视图互补帧选择已存在。

**边界**：完全不可见结构不被新增普通外视图保证辨别；已采视频选择不同于在线采集。

### AX2610_11954

[SightCAD](/cad/papers/ax2610_11954)

**已经解决**：可达视角、遮挡分层、预算选择、policy-neutral/coadapted和真实图像评测均已做。

**边界**：候选图全可见、姿态/锚点条件及固定格限制仍明确；不声称它违反自身定义。

### Lu26g

[CADForge](/cad/papers/lu26g)

**已经解决**：组件级显式几何推理与复核能改善单图重建。

**边界**：推理不能替代不存在的观测；极端视角仍可能漏几何。

有直接证据的边界是受限视觉输入下隐藏结构与几何细节仍难确认。可进一步研究“仅已采图可见、总采集成本受限、位姿带误差”的在线协议及必要澄清；其相对已有offline选择的收益尚未验证，不能写成全领域无人做主动观察。

## 原因解释与待验证方法

**来源材料中的机制解释**

- 已核方法仍有相机/锚点条件、单图或不可见内部几何限制。
- SightCAD选择器使用全候选图，因此原协议是视图子集优化，不能直接等同未知图像的机器人采集。

**待验证的原因假设**

- 在已观察图像下维护少量相容CAD候选，再选择能区分候选的可达动作，可能比纯表面积覆盖更节约真正采集预算。
- 对不可区分的内部结构请求一次尺寸/剖视/存在性澄清，可能比强行生成确定结果更可靠。

### 仅用已采观测的候选分歧驱动下一视角

**实施机制**：以当前可见图生成少量相容CAD候选，渲染候选预测的下一视角并估计结构分歧，在可达动作集选择；执行一次拍摄后更新。禁止读取尚未采的真实候选图。

**相对近邻的拟议变化**：SightCAD/VGGT已有子集选择；这里的研究变量是信息访问与实际采集计费。一般NBV已有不确定性方法，不能称首次；必须对照同信息的coverage/uncertainty NBV。

**成立条件**：可在仿真中控制相机和可达集合；候选能反映部分真实歧义，首轮不需要物理机器人。

**失败风险**：候选全部同错且过度自信时分歧为零；相机误差会误把位姿变化当几何差异。

### 观测不足时的结构化澄清与保守输出

**实施机制**：对始终不能从可达视图区分的结构，保留未确定字段，并用固定问题预算请求孔是否贯通、一个厚度或剖面信息；比较拒答/多假设与单一猜测。

**相对近邻的拟议变化**：不是用LLM猜隐藏部分；必须证明澄清问题能减少结构错误且信息成本可计量，和给相同额外测量的基线公平比较。

**成立条件**：允许用户提供真实测量/剖面或是仿真oracle；oracle仅回答请求的问题。

**失败风险**：没有用户或传感补充时只能保留不确定，不能保证完成唯一CAD；任务交互成本可能抵消收益。

## 数据与标注安排

**数据安排**

- DS_CADRecode与DS_Text2CAD可渲染程序几何用于受控遮挡；DS_F360_Reconstruction作为不同来源检查但遵守许可。

**所需标注**

- 可达相机、采集动作成本、位姿噪声、可见/不可见特征、在观察下等价的候选结构与澄清答案。

**构造方式**

在可执行零件上加墙/桌面/遮挡，产生同外观但孔深/空腔不同的成对对象；序列运行时只释放已采图。完全封闭内部的歧义单列，不期望外部视图解决。

**许可说明**

CAD-Recode非商业许可；Text2CAD gated且CC BY-NC-SA；Fusion360仅非商业研究及有限再分发。场景/相机与原模型来源一并保留。

**来源与泄漏控制**

成对相似模型、所有视角与场景配置按原对象/骨架分组；未采图和GT形状只给评分器，不给策略。

## 最小验证与否定条件

以下为验证方案，所列阈值是预设判据。

**可证伪假设**

在相同初始视角、可达相机、累计实际拍摄数和总生成/执行预算下，在线候选分歧与有限澄清减少不可见特征错误，且对位姿噪声更可校准。

**比较基线**

- 随机/均匀/几何覆盖NBV（只用已采观测）
- 同信息的一般不确定性NBV
- SightCAD/VGGT离线候选选择作为更强信息上界，单独列而不装成同信息公平胜负
- 单图CADForge式固定推理预算与所有方法获得同次数澄清的对照

**数据划分**

对象/骨架heldout并留未见遮挡布局；相机角噪声、距离/尺度噪声分层；相同对象/姿态起点paired比较。

**指标**

- 按真实拍摄数的有效性/几何/特征正确率曲线
- 可见与不可见区域分别的孔/厚度/结构错误
- 高置信错误率、选择性风险/覆盖、澄清次数
- 实际图像读取数、相机动作数、候选生成与推理成本

**消融**

- 允许窥看全部候选图的offline oracle
- 去候选分歧仅覆盖
- 去位姿不确定性
- 去澄清；给所有方法相同额外测量

**预设支持判据**

信息严格匹配时，用较少实际采图达到预设结构正确率，或同预算减少不可见特征高置信错误；给paired CI并分别报告可辨识与不可辨识组。

**否定或收缩条件**

收益依赖未采图/GT pose/形状泄漏、只在离线子集计费成立，或补充信息后普通基线同样解决；不能宣称策略本身贡献。

**最小起步规模**

先约100个程序对象、三种遮挡和2–5次采图的仿真episode，先冻结生成器，不训练大型多模态模型或部署机器人。
