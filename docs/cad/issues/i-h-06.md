# 网格细化选点看似更准，仍不一定降低关键应力误差

## 实际场景与失败条件

**场景**：让MLLM从多视图和载荷描述建议细化位置，在有限单元数下提高FEA关键应力的准确性。

**失败条件**：GReFEM v2 §5.2明确localization overlap与下游FEM误差不一致；§5.1/Limitations中load-informed heuristic优于GReFEM，重训AMBER可比；prompt命中特征更多不等于数值更好。

**后果**：只以F1/recall奖励选点或只对比blind几何基线，可能宣称没有工程收益的改进。

## 原论文证据

### Bal26 · §5.1 Tables1–3；§5.2；§6 Limitations；Appendix A.3

156件×5载荷、预算匹配对照；overlap非主验收，强载荷启发式更优，细化幅度固定且仅线弹性。

## 已有方案与剩余边界

### Bal26

[GReFEM](/cad/papers/bal26)

**已经解决**：已经用matched budget与FEM误差纠正单纯overlap评价，并有load-informed/AMBER对照。

**边界**：剩余是如何按下游误差和预算选择位置及尺度，不能再以“改用物理指标”当新贡献。

在GReFEM公开的线弹性测试范围，MLLM选择策略仍有到参考oracle差距且不胜最强载荷启发式；有无可学习改进必须与这些强基线公平比较。

## 原因解释与待验证方法


**来源材料中的机制解释**

- overlap给每个critical点相同权，而peak stress受少数热点支配；GReFEM只决定where，细化强度固定。


**待验证的原因假设**

- 按热点误差收益分配细化强度并选择MLLM/解析启发式/求解器回退，可在给定时间预算下改善。


### 误差收益驱动的细化分配

**实施机制**：由几何特征+载荷+廉价粗解估计候选局部细化对关键应力的边际收益，再在单元/时间预算内同时选择位置和h；明确计入粗解成本。

**相对近邻的拟议变化**：与GReFEM固定幅度不同，直接优化下游误差—成本；不默认MLLM不可替代。

**成立条件**：可用少量参考解构造候选收益标签。

**失败风险**：标签昂贵，学习分配器可能不如简单load启发式。

### 带失败回退的策略选择

**实施机制**：在可用闭式载荷族优先用load-informed启发式，未知/复杂情形比较MLLM与粗解建议；不确定或无anchor时返回标准AMR，不把失败样本排除。

**相对近邻的拟议变化**：研究价值是条件选择/预算可靠性，而非必须训练更大LLM。

**成立条件**：载荷域可识别，基线均可运行。

**失败风险**：选择器校准不准或调用多个策略消耗过多。

## 数据与标注安排


**数据安排**

- DS_ABC


**所需标注**

明确载荷/支持、参考应力场、候选局部mesh收益


**构造方式**

选30–50简单CAD与3–5载荷，先做网格收敛与参考解；保持几何源uid，参考解只作监督/终验。


**许可说明**

ABC模型与衍生条款依原来源，新增载荷/仿真标签单独说明。


**来源与泄漏控制**

按CAD source与load family留出；同模型全部mesh/视图同组。


## 最小验证与否定条件

以下均为计划，不是已完成实验或学术创新结论。


**可证伪假设**

条件策略/位置尺度联合分配优于同总计算预算的最强单一策略。


**比较基线**

- blind heuristic
- load-informed heuristic
- coarse ZZ
- AMBER适用实现
- GReFEM式where固定h
- fine-solve oracle仅上界


**数据划分**

未知CAD和未见载荷族分开报；每方法计入render、模型call、coarse solve与meshing时间。


**指标**

- p99应力相对误差
- 临界域能量误差
- 网格失败率
- 总wall time
- 单元数
- overlap仅诊断


**消融**

- 只where
- 固定h
- 去回退
- 无粗解成本记账


**预设支持判据**

在相同总预算而非只单元数下优于强load baseline，且不靠过滤无anchor/mesh失败case。


**否定或收缩条件**

只优于blind而不及解析法，或需要昂贵参考solve才有收益。


**最小起步规模**

30–50件×3–5载荷作profile；正式实验按CPU参考解成本扩展。
