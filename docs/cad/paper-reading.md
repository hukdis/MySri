# 论文解读模板

::: info 等待第一篇论文 · cad-0001
这是阅读框架，不是对某篇论文的解读。CAD 的具体方向与论文来源确认后再填入内容。
:::

## 论文信息

记录标题、作者、年份、发表渠道、论文链接、代码链接和使用的版本。没有公开代码时明确说明，不推测实现。

## 研究问题

用自己的话解释论文试图解决什么问题、输入输出是什么，以及为什么已有方法不足。为对应论述注明章节或页码。

## 前置知识

列出理解方法需要的概念，链接到本站相关文章。暂时没有文章的概念可标记为待补充。

## 核心方法

先解释直觉，再分解流程、变量和关键公式。每个模块说明输入、输出、作用与假设；区分论文描述与阅读者的解释。

## 实验依据

| 要检查的内容 | 阅读时需要记录 |
| --- | --- |
| 数据与任务 | 数据集、切分方式、任务范围 |
| 对比方法 | 比较对象及设置是否公平 |
| 指标 | 指标定义、方向与局限 |
| 结果 | 数值、表格位置及适用条件 |
| 消融实验 | 哪个模块的作用得到支持 |

## 局限与未解决的问题

分别记录作者承认的局限、自己发现的问题和需要进一步验证的猜想。

## 我的理解

个人笔记保存到 `notes/cad-0001.md`，整理成正式文章时为实际论文分配新 ID。记录“我能解释的部分”和“仍不明白的部分”。

## 下一步

选择一个可以检查的行动：复现一个结果、读一篇前置论文，或画出方法流程。
