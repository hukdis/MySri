# 具体问题与待验证方法

26 项问题按四任务组织。22 项在来源资料中标为原文支持的范围限定问题，4 项为候选；这些标签不代表所有方法或全部情形都有相同失败。

## 如何使用证据

先核对失败条件、论文版本与已经存在的解决方案，再评估拟议方法的独立增量。AI 原因解释、计划阈值和候选方法均须验证。
