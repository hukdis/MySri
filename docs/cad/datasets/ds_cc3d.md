# CC3D / SHARP 2023


## 任务、格式与版本

- **任务入口**：[CAD重建](/cad/tasks/reconstruction)
- **格式**：扫描点云 · B-Rep边/面标注 · 操作类型/顺序
- **规模**：项目称5万余CAD/扫描配对；PSE、BRep、OPS各轨实际子集另核
- **年份依据**：关联论文年份；不自动等于数据包首次公开时间

## 官方入口与获取记录

- [原始来源 1](https://cvi2.uni.lu/sharp2023-challenge/)

- **记录状态**：需申请授权
- **资料核查日期**：2026-10-15
- **核查范围**：官方说明/数据卡核对；具体样本与端点检查另列
- **存储与获取**：官方未给出可靠总大小；先查看文件列表再分批获取

公开入口与许可条件分开判断；本轮未下载完整数据集或进行训练

## 许可、划分与来源

**数据许可**

需申请并由各方签署数据许可协议

**代码许可**

见官方仓库，代码与数据分开核查

**使用条件**

按此版本数据页和逐文件附带条件使用；本表为来源记录，不替代原条款

**官方划分**

按获授权轨道的官方训练/测试协议，申请前比例未核实

**分组单位**

原始CAD模型/设计文档

**泄漏检查**

同一模型的不同文本、视图、噪声和派生版本应留在同一数据组；另做几何近重复检查

**说明**

按原始模型标识保存来源，不把模态变体计作独立设计

## 最小使用方式

**使用步骤**

- 通过官方注册页选择PSE/BRep/OPS轨道并申请数据协议，当前未替用户发邮件。
- 取得授权后锁定具体轨道和split，不把全部CC3D规模当某轨训练规模。
- 使用作者I/O例程核对扫描点与边、面或操作标签，保留每轨评价协议。

**执行后端**

先检查文件与配对，再按官方环境准备CAD执行后端

**预期产物**

保留下载版本、文件清单、样本标识、划分及核查日志

## 已知限制

- 不能按免登录公开下载规划首个实验。
- 各轨目标不同，法线、边界或历史标签不能互相当替代。

## 样例检查范围

样例文件或格式检查不等于 CAD 内核有效性检查，也不代表全部数据均可获取。
