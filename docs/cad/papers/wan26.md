# Text2CAD-Bench


## 论文信息

- **全名**：Text2CAD-Bench: A Benchmark for LLM-based Text-to-Parametric CAD Generation
- **作者**：Liang Wang、Heng Meng、Zekai Xiang、Jin Liu、Pingyi Zhou、Litao Chen、Yongqiang Tang
- **论文时间**：2026-05-18（arXiv首次提交）

## 任务定位

研究任务：共用基础。

复杂度分层的文本参数化CAD生成评价资源。

## 方法与贡献

- 按照几何复杂度和应用范围组织文本到CAD评价，包含不同描述风格及更复杂的特征。它补充简单草图拉伸场景之外的诊断能力。基准用于评价，不能默认转成训练集后仍作为独立测试。

## 技术要点

- **输入**：文本

- **要求**：几何
