# CAD落地装配说明


## 论文信息

- **全名**：Automated Assembly Instruction Generation from CAD Models Using Grounded Large Language Models: A Human-in-the-Loop Framework
- **作者**：Aaron Dsouza、Mohammed Azeez Khan、Ashutosh Mishra、Arshaan Khan、Neha K. Nair、Amar Kumar Behera
- **论文时间**：2026-10-08（arXiv首次提交）

## 任务定位

研究任务：[CAD理解、评估与规划](/cad/tasks/analysis)。

从STEP装配生成受产品图约束的装配说明和过程。

## 方法与贡献

- 从STEP装配提取类型化产品图，以确定性排序和受图上下文约束的语言生成形成装配说明。它加入规则、模型及人工检查，限制未解决质量问题时的文档发布。论文只建立小型案例的端到端可行性，泛化与几何验证仍是开放问题。

## 技术要点

- **输入**：CAD

- **表示**：装配图

- **方法**：语言模型 · 规则检查

- **对象**：装配

- **要求**：装配 · 规格验证
