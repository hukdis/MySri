# 几何约束的自由度分析


## 论文信息

- **全名**：Solving Geometric Constraint Systems
- **作者**：Glenn A. Kramer
- **论文时间**：1990（正式/机构年份记录）
- **正式发表记录**：1990；AAAI 1990

## 任务定位

研究任务：共用基础。

几何约束求解与自由度理论属于共用基础。

## 方法与贡献

- 提出按剩余自由度逐步满足几何约束的推理方式，减少将所有约束直接变成耦合代数方程的负担。它说明几何求解可以利用对象及约束本身的结构。后续大模型约束路线与它共享问题背景，本树未将这种共同背景当成直接模型继承。

## 技术要点

- **方法**：约束求解

- **对象**：草图

- **要求**：约束
