# Sketch2CAD


## 论文信息

- **全名**：Sketch2CAD
- **作者**：Changjian Li、Hao Pan、Adrien Bousseau、Niloy J. Mitra
- **论文时间**：2020-11-27（正式/机构年份记录）
- **正式发表记录**：2020-11-27；ACM Transactions on Graphics

## 任务定位

研究任务：[CAD编辑](/cad/tasks/editing)。

在当前CAD上下文中解释新增笔画并修改模型，主任务是编辑。

## 方法与贡献

- 利用当前部分CAD模型作为上下文，解释新画的笔画并将它们转换为CAD修改操作。它降低逐步草图建模中的二维歧义。输入强调逐步绘制及当前上下文，与一次读入完整工程图的重建任务不同。

## 技术要点

- **输入**：草图 · 已有CAD

- **表示**：命令序列

- **对象**：零件

- **要求**：可编辑性
