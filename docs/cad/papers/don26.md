# CADWorld


## 论文信息

- **全名**：CADWorld: Computer-Use Benchmark for Long-Horizon Computer-Aided Design
- **作者**：Zihan Dong、Yuanzhe Liu、Zhiyuan Ma、Qishi Zhan、Dehan Kong、Guohao Li、Kaixin Li
- **论文时间**：2026-09-14（arXiv首次提交）

## 任务定位

研究任务：共用基础。

桌面长程CAD操作基准，GUI是接口标签而非独立研究任务。

## 方法与贡献

- 建立FreeCAD桌面长程操作基准，通过截图与GUI动作完成建模、装配、加工和分析等任务。成功由保存工程文件的可执行检查决定，覆盖尺寸、构造结构和工程状态。它评价的是计算机使用代理，不能直接等同Python API代码生成基准。

## 技术要点

- **输入**：图像 · 交互

- **要求**：可执行性 · 装配 · 物理功能
