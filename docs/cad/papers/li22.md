# Free2CAD


## 论文信息

- **全名**：Free2CAD
- **作者**：Changjian Li、Hao Pan、Adrien Bousseau、Niloy J. Mitra
- **论文时间**：2022-07（正式/机构年份记录）
- **正式发表记录**：2022-07；ACM Transactions on Graphics

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

自由手绘表达用户希望创建的物体，按设计条件生成；不因草图输入自动列入逆向工程。

## 方法与贡献

- 把用户绘制的最终形状笔画序列翻译为一系列简化CAD命令，并处理笔画分组与多操作解析。相较要求用户逐步表达单个操作的交互范式，它允许更自由的整体草图输入。这里按公开摘要描述范式差别，未将其画成已核实继承Sketch2CAD架构的连线。

## 技术要点

- **输入**：草图

- **表示**：命令序列

- **对象**：零件

- **要求**：几何
