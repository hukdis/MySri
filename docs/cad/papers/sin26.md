# CADEngBench


## 论文信息

- **全名**：CADEngBench: It Looks Like CAD, but Does It Work? Evaluating Parametric Design, Assembly Reasoning, and Physics Simulation
- **作者**：Harmanjot Singh、Abhra Dubey、Jorge Alejandro Amador Herrera
- **论文时间**：2026-08-10（arXiv首次提交）

## 任务定位

研究任务：共用基础。

工程行为和参数扰动的评测资源，不归为工程方法方向。

## 方法与贡献

- 同时检查参数化零件和装配的工程行为，包括编辑、参数扰动、配合实体、运动及声明的结构分析。它把CAD评价扩展到几何外形之外的可用性。所有物理结论都受所声明材料、载荷和仿真协议约束，不能视为通用安全认证。

## 技术要点

- **输入**：已有CAD

- **表示**：B-Rep

- **对象**：零件 · 装配

- **要求**：运动 · 装配 · 物理功能
