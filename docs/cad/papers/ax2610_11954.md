# SightCAD


## 论文信息

- **全名**：Look Where You Can: Active View Selection for CAD Reconstruction under Occlusion
- **作者**：Kartik Bali、Mahish Guru、Yiderigun Borjigin、Alexandra Starostina、Christian J. Cyron、Roland Aydin
- **论文时间**：2026-10-08（arXiv首次提交）

## 任务定位

研究任务：[CAD重建](/cad/tasks/reconstruction)。

有限可达视角下恢复指定对象。

## 方法与贡献

- 把场景遮挡和可达视角作为重建条件，学习选择有限可行视图并联合训练CAD代码生成模型。它改变以往可自由观察目标的假设。场景合成、真实输入处理和总视图预算都应与其他多视图方法分开核查。

- **输入**：图像

- **表示**：CAD程序

- **方法**：主动观察 · 视觉语言模型

- **对象**：零件

- **要求**：几何
