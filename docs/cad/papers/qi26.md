# Pointer-CAD v2 · 先规划再构造


## 论文信息

- **全名**：Pointer-CAD v2: Plan-Then-Construct CAD Generation with Dimension-Aware Parametric Precision
- **作者**：Qi, Dacheng、Wang, Chenyu、Xu, Jingwei、Ma, Yi、Gao, Shenghua
- **论文时间**：2026-06-28（arXiv首次提交）

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

按连续数值设计计划构造新CAD，不将内部规划另设方向。

## 方法与贡献

- 针对参数量化会破坏精确尺寸的问题，在Pointer-CAD v1基础上把参数推理与几何构造解耦。它先生成含连续数值和实际尺度的设计计划，再通过字典指针在命令生成中引用参数，并引入计划标注数据与分层几何精度指标。消除量化误差不等于消除模型预测误差，数据和实验设置仍需按v2独立核查，不能与v1默认合并。

## 技术要点

- **输入**：文本

- **表示**：命令序列

- **方法**：指针选择 · 语言模型

- **对象**：零件

- **要求**：尺寸 · 实体引用
