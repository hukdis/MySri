# 生成式几何的语义


## 论文信息

- **全名**：On the Semantics of Generative Geometry Representations
- **作者**：Christoph M. Hoffmann
- **论文时间**：1993（正式/机构年份记录）
- **正式发表记录**：1993；Purdue University, Computer Science Technical Report 93-010

## 任务定位

研究任务：共用基础。

生成几何语义与参数依赖的理论基础。

## 方法与贡献

- 指出特征、附着关系和约束定义的构造操作需要严格语义，单靠静态边界表示难以说明这些生成过程。它把建模过程的含义作为独立研究问题。该节点来自1993技术报告，属于概念基础，不是可直接训练的CAD生成模型。

## 技术要点

- **对象**：零件

- **要求**：可编辑性
