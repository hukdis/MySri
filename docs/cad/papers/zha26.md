# BenchCAD


## 论文信息

- **全名**：BenchCAD: A Comprehensive, Industry-Standard Benchmark for Programmatic CAD
- **作者**：Haozhe Zhang、Kaichen Liu、Miaomiao Chen、Lei Li、Shaojie Yang、Cheng Peng、Hanjie Chen
- **论文时间**：2026-05-11（arXiv首次提交）

## 任务定位

研究任务：共用基础。

工业程序化CAD多任务诊断基准。

## 方法与贡献

- 把工业零件的视觉理解、代码理解、图像生成和指令编辑放进统一程序化CAD基准。它检查模型是否理解结构、工程参数和所需操作，而不只恢复外轮廓。对未见零件族的泛化需要与分布内微调提升分开分析。

## 技术要点

- **输入**：文本 · 图像 · 已有CAD

- **要求**：几何 · 可编辑性
