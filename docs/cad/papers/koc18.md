# ABC


## 论文信息

- **全名**：ABC: A Big CAD Model Dataset for Geometric Deep Learning
- **作者**：Sebastian Koch、Albert Matveev、Zhongshi Jiang、Francis Williams、Alexey Artemov、Evgeny Burnaev、Marc Alexa、Denis Zorin、Daniele Panozzo
- **论文时间**：2019-06（正式/机构年份记录）
- **正式发表记录**：2019-06；2019 IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)

## 任务定位

研究任务：共用基础。

精确CAD几何数据集，不把数据资源当成方法任务。

## 方法与贡献

- 提供大规模参数曲线和曲面CAD数据，使几何学习可以获得精确曲面、边界和多分辨率采样。它为法向、分割和重建等任务提供共同数据基础。数据含精确几何，不应默认含完整人类建模历史。

## 技术要点

- **输入**：B-Rep

- **表示**：B-Rep

- **对象**：零件

- **要求**：几何
