# CANTO


## 论文信息

- **全名**：CANTO: CAD-Native Transformer Operators for AI-Aided Engineering
- **作者**：Daniel Leibovici、Nikola Borislavov Kovachki、Dawon Ahn、Ruben Ohana、Ira J. S. Shokar、Abouzar Ghasemi、Semih Akkurt、Rishikesh Ranade、Neil Ashton、Jan Kautz、Jean Kossaifi
- **论文时间**：2026-09-29（arXiv首次提交）

## 任务定位

研究任务：[CAD理解、评估与规划](/cad/tasks/analysis)。

从连续CAD预测物理场为主，参数逆设计为次用途；不标作预训练LLM。

其他任务：[CAD生成](/cad/tasks/generation)

## 方法与贡献

- 直接把连续CAD的NURBS曲面编码为词元，学习从几何到物理场的神经算子。它尝试减少将几何先离散成网格后再做预测的表示断层，并支持参数化逆设计。属于工程分析邻接路线，Transformer算子并不意味着使用预训练LLM。

## 技术要点

- **输入**：几何

- **表示**：参数曲面

- **方法**：神经算子

- **对象**：零件

- **要求**：物理功能
