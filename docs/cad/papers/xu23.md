# HNC-CAD


## 论文信息

- **全名**：Hierarchical Neural Coding for Controllable CAD Model Generation
- **作者**：Xiang Xu、Pradeep Kumar Jayaraman、Joseph G. Lambourne、Karl D. D. Willis、Yasutaka Furukawa
- **论文时间**：2023-06-30（arXiv首次提交）

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

层次码树条件生成及部分补全，以生成任务为主。

## 方法与贡献

- 以实体、轮廓和环的层次码树组织CAD表示，并让部分输入与层次代码共同控制生成。论文明确使用并修改SkexGen的码本与解码基础，推进层次控制和设计变化。支持的建模操作仍以草图拉伸为主。

## 技术要点

- **输入**：部分CAD

- **表示**：命令序列

- **方法**：自回归 · 码本

- **对象**：零件

- **要求**：几何
