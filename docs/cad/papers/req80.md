# 实体表示理论


## 论文信息

- **全名**：Representations for Rigid Solids: Theory, Methods, and Systems
- **作者**：Aristides G. Requicha
- **论文时间**：1980-12（正式/机构年份记录）
- **正式发表记录**：1980-12；ACM Computing Surveys

## 任务定位

研究任务：共用基础。

刚体表示理论，供理解表示与恢复任务使用。

## 方法与贡献

- 系统梳理刚性实体的表示、几何语义和计算方法，帮助区分边界表示与构造表示的能力和限制。它提供比较CAD输出表示的理论框架。本文属于表示基础，不能据此认为边界几何天然保存参数依赖或建模历史。

## 技术要点

- **表示**：B-Rep · CSG

- **对象**：零件

- **要求**：几何
