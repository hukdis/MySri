# SkexGen


## 论文信息

- **全名**：SkexGen: Autoregressive Generation of CAD Construction Sequences with Disentangled Codebooks
- **作者**：Xiang Xu、Karl D. D. Willis、Joseph G. Lambourne、Chin-Yi Cheng、Pradeep Kumar Jayaraman、Yasutaka Furukawa
- **论文时间**：2022-07-11（arXiv首次提交）

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

通过解耦码本生成新CAD序列。

## 方法与贡献

- 将草图拓扑、几何与拉伸变化分解到离散码本，并自回归生成CAD构造序列。论文明确在TurtleGen和DeepCAD表示基础上修改，增加面层次来扩展表达。它提高可控生成能力，但离散拓扑变化仍会影响平滑插值。

## 技术要点

- **表示**：命令序列

- **方法**：自回归 · 码本

- **对象**：零件

- **要求**：几何 · 拓扑
