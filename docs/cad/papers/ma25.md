# CADMorph


## 论文信息

- **全名**：CADMorph: Geometry-Driven Parametric CAD Editing via a Plan-Generate-Verify Loop
- **作者**：Weijian Ma、Shizhao Sun、Ruiyu Wang、Jiang Bian
- **论文时间**：2025-12-12（arXiv首次提交）

## 任务定位

研究任务：[CAD编辑](/cad/tasks/editing)。

用目标几何计划并补全已有CAD序列的修改。

## 方法与贡献

- 用几何目标引导参数化序列编辑，通过计划、补全和验证组合预训练形状及参数模型。它尝试在缺少编辑三元组时利用模型先验保持原序列结构。输入强调目标几何，不能直接视为与纯自然语言编辑完全相同的任务。

## 技术要点

- **输入**：已有CAD · 目标几何

- **表示**：命令序列

- **方法**：搜索 · 执行反馈

- **对象**：零件

- **要求**：可编辑性 · 内容保持
