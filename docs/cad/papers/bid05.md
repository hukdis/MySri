# 特征级持久实体


## 论文信息

- **全名**：A Feature-Based Solution to the Persistent Naming Problem
- **作者**：Rafael Bidarra、Paulos J. Nyirenda、Willem F. Bronsvoort
- **论文时间**：2005-01（正式/机构年份记录）
- **正式发表记录**：2005-01；Computer-Aided Design and Applications

## 任务定位

研究任务：共用基础。

特征式持久命名提供编辑与引用的历史背景。

## 方法与贡献

- 分析参数化重算时引用非持久几何实体导致的不稳定行为，并提出以持久参数实体组织模型的方案。相较只补救名称映射，它重新讨论模型中应当引用什么。这里采用论文摘要解释贡献，不声称该方法已经统一解决现代CAD后端的命名问题。

## 技术要点

- **对象**：零件

- **要求**：实体引用
