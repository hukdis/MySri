# 早期机械设计语言框架


## 论文信息

- **全名**：A Linguistic Approach Proposal for Mechanical Design Using Natural Language Processing
- **作者**：João Carlos Linhares、Altamir Dias
- **论文时间**：2003（正式/机构年份记录）
- **正式发表记录**：2003；Lecture Notes in Computer Science, Computational Processing of the Portuguese Language

## 任务定位

研究任务：共用基础。

早期自然语言机械设计框架提案；贡献仅据有限书目材料保守定位。

## 方法与贡献

- 提出在初步机械设计中捕获设计者自然语言的计算框架，并将技术语言与参数特征的几何及非几何属性建立联系。它说明语言驱动机械设计在LLM出现前已有研究。原文将其表述为框架提案，不应写成已验证的现代开放域文本到CAD系统。

## 技术要点

- **输入**：文本
