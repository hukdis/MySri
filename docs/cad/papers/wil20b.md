# Fusion 360 Gallery


## 论文信息

- **全名**：Fusion 360 Gallery: A Dataset and Environment for Programmatic CAD Construction from Human Design Sequences
- **作者**：Karl D. D. Willis、Yewen Pu、Jieliang Luo、Hang Chu、Tao Du、Joseph G. Lambourne、Armando Solar-Lezama、Wojciech Matusik
- **论文时间**：2020-10-05（arXiv首次提交）
- **正式发表记录**：2021-07-19；ACM Transactions on Graphics
- **版本说明**：索引题名与当前原文题名不同，保留索引题名供检索。

## 任务定位

研究任务：共用基础。

Gallery数据与构造环境主要支撑历史恢复。

## 方法与贡献

- 提供人工设计的草图拉伸程序和可交互构造环境，把CAD重建定义为恢复可执行建模步骤。它连接真实设计序列、环境执行与模型学习。原始构造数据与后来装配数据属于不同发布内容，需要分别记录。

## 技术要点

- **输入**：CAD

- **表示**：命令序列

- **对象**：零件

- **要求**：构造历史
