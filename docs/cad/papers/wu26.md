# IterCAD · 正投影修复


## 论文信息

- **全名**：IterCAD: Iterative Program Repair for CAD Code Generation from Orthographic Views
- **作者**：Yuchuan Wu、Ke Niu、Haiyang Yu、Zhuofan Chen、Xiangyang Xue、Bin Li
- **论文时间**：2026-08-25（arXiv首次提交）

## 任务定位

研究任务：[CAD重建](/cad/tasks/reconstruction)。

带尺寸正投影图的目标重建；修订与停止属于重建内部策略。

## 方法与贡献

- 从带尺寸的正投影图生成程序，并将后续推理组织为修订或停止的多轮过程。它构造修复监督并结合初始生成、修订学习和多轮优化，区别于只预测一次最终程序。迭代需要公平计算预算和停止评价，且不能与另一篇同名IterCAD合并。

## 技术要点

- **输入**：图纸

- **表示**：CAD程序

- **方法**：监督微调 · 强化学习 · 执行反馈

- **对象**：零件

- **要求**：几何 · 尺寸
