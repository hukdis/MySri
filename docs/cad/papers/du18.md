# InverseCSG


## 论文信息

- **全名**：InverseCSG
- **作者**：Tao Du、Jeevana Priya Inala、Yewen Pu、Andrew Spielberg、Adriana Schulz、Daniela Rus、Armando Solar-Lezama、Wojciech Matusik
- **论文时间**：2018-12-04（正式/机构年份记录）
- **正式发表记录**：2018-12-04；ACM Transactions on Graphics

## 任务定位

研究任务：[CAD重建](/cad/tasks/reconstruction)。

由目标形状恢复CSG程序，而非从需求自由设计。

## 方法与贡献

- 从三维形状恢复CSG程序，将几何信息与程序综合结合起来。它提供了学习神经生成之外的构造恢复路线。其输出重点是CSG组合，不自动恢复设计师原始的特征树和参数意图。

- **表示**：CSG

- **方法**：程序综合 · 搜索

- **对象**：零件

- **要求**：几何
