# Point2Cyl


## 论文信息

- **全名**：Point2Cyl: Reverse Engineering 3D Objects from Point Clouds to Extrusion Cylinders
- **作者**：Mikaela Angelina Uy、Yen-Yu Chang、Minhyuk Sung、Purvi Goel、Joseph Lambourne、Tolga Birdal、Leonidas Guibas
- **论文时间**：2022-06（正式/机构年份记录）
- **正式发表记录**：2022-06；2022 IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)

## 任务定位

研究任务：[CAD重建](/cad/tasks/reconstruction)。

由点云恢复挤出结构。

## 方法与贡献

- 从点云恢复可组成模型的拉伸柱体及其轮廓、方向等参数，把三维重建推进到建模操作层面。它让点云反演与草图拉伸建模联系起来。范围主要是相应拉伸结构，不能直接代表所有工业CAD操作。

## 技术要点

- **输入**：点云

- **表示**：命令序列

- **方法**：监督学习

- **对象**：零件

- **要求**：几何
