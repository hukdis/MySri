# 持久拓扑命名


## 论文信息

- **全名**：A mechanism for persistently naming topological entities in history-based parametric solid models
- **作者**：Jiri Kripac
- **论文时间**：1995-12（正式/机构年份记录）
- **正式发表记录**：1995-12；Proceedings of the third ACM symposium on Solid modeling and applications
- **版本说明**：1995会议书目已核实；机制说明参考1997同题期刊摘要，完整版本差异待核查。

## 任务定位

研究任务：共用基础。

持久命名基础，不视为现代实体指针方法。

## 方法与贡献

- 研究历史建模步骤修改后，如何继续识别对应的面、边和顶点。持久ID及对应映射把实体引用问题从单次几何定位推进到重算后的追踪。1995会议稿的书目已核实，机制描述参考1997同题期刊版的可见摘要；两个版本的完整差异尚未核查。

## 技术要点

- **对象**：零件

- **要求**：实体引用
