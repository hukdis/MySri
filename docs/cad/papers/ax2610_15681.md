# HiCAD · Human Intent-to-CAD


## 论文信息

- **全名**：Rethinking Human Intent-to-CAD: Parametric CAD Model Generation via Cooperative Multi-Task Alignment and Spatial-Aware Reinforcement Learning
- **作者**：Qingwang Zhang、Jiahao Li、Xiangdong Zhou
- **论文时间**：2026-10-11（arXiv首次提交）

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

不完整手绘和文本表达概念设计意图，不预设目标CAD存在。

## 方法与贡献

- 把手绘草图、文本等不完整设计意图对齐到可执行CAD代码，并建立对应多模态数据。它结合多任务对齐与空间感知强化学习，面向概念设计而不预设目标CAD已存在。当前为2026年10月11日可核实的预印本，性能主张仍需全文和统一协议核查。

- **表示**：CAD程序

- **方法**：视觉语言模型 · 强化学习

- **对象**：零件

- **要求**：几何
