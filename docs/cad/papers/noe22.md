# Mates2Motion


## 论文信息

- **全名**：Mates2Motion: Learning How Mechanical CAD Assemblies Work
- **作者**：James Noeckel、Benjamin T. Jones、Karl Willis、Brian Curless、Adriana Schulz
- **论文时间**：2022-08-02（arXiv首次提交）

## 任务定位

研究任务：[CAD理解、评估与规划](/cad/tasks/analysis)。

从已有配合关系推断自由度与运动轴。

## 方法与贡献

- 从机械装配的CAD配合关系学习零件之间的自由度和可能运动轴。它进一步检查配合定义是否体现实际运动，并建立更可靠的运动标注测试。识别运动与生成完整装配程序是不同任务。

## 技术要点

- **输入**：CAD

- **表示**：约束图

- **对象**：装配

- **要求**：运动 · 装配
