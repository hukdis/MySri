# Semantic Direct Modeling


## 论文信息

- **全名**：Semantic Direct Modeling
- **作者**：Qiang Zou、Shuo Liu
- **论文时间**：2025-04-05（arXiv首次提交）

## 任务定位

研究任务：[CAD编辑](/cad/tasks/editing)。

从修改意图识别语义特征并执行直接修改。

## 方法与贡献

- 将自然语言设计意图映射到当前CAD中的语义特征，再执行低层几何修改。它把直接建模从逐个点边面的操作提升到意图和特征层面。特征识别的上下文依赖和真实应用覆盖仍需按原文案例检查。

## 技术要点

- **输入**：文本 · 已有CAD

- **表示**：B-Rep

- **方法**：语言模型

- **对象**：零件

- **要求**：可编辑性 · 语义理解
