# CADFS


## 论文信息

- **全名**：CADFS: A Big CAD Program Dataset and Framework for Computer-Aided Design with Large Language Models
- **作者**：Vladislav Pyatov、Gleb Bobrovskikh、Saveliy Galochkin、Nikita Boldyrev、Oleg Voynov、Alexander Filippov、Gonzalo Ferrer、Peter Wonka、Evgeny Burnaev
- **论文时间**：2026-05-03（arXiv首次提交）
- **正式发表记录**：2026-06；Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR), pp. 10176–10186

## 任务定位

研究任务：共用基础。

丰富真实操作与多模态标注的数据资源，模型作为使用基线。

## 方法与贡献

- 用FeatureScript表示较丰富的真实建模操作，重建可执行程序并添加多模态标注。它扩展常见草图拉伸数据受限的操作范围，再用相应数据训练视觉语言模型。数据可用性和后端依赖应按实际发布材料确认。

## 技术要点

- **输入**：文本 · 图像

- **表示**：FeatureScript

- **对象**：零件

- **要求**：构造历史
