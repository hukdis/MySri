# 几何约束求解综述


## 论文信息

- **全名**：A review on geometric constraint solving
- **作者**：Qiang Zou、Zhihong Tang、Hsi-Yung Feng、Shuming Gao、Chenchu Zhou、Yusheng Liu
- **论文时间**：2022-02-28（arXiv首次提交）

## 任务定位

研究任务：共用基础。

几何约束求解综述，归入基础阅读资料。

## 方法与贡献

- 整理几何约束求解的技术路线、发展和适用问题，为阅读分解、代数求解及数值求解提供入口。它用于理解现代求解器反馈的来源，而不是新增大模型算法。具体方法细节应回查被综述的原论文。

## 技术要点

- **方法**：约束求解

- **对象**：草图

- **要求**：约束
