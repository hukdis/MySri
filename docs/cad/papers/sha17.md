# CSGNet


## 论文信息

- **全名**：CSGNet: Neural Shape Parser for Constructive Solid Geometry
- **作者**：Gopal Sharma、Rishabh Goyal、Difan Liu、Evangelos Kalogerakis、Subhransu Maji
- **论文时间**：2018-06（正式/机构年份记录）
- **正式发表记录**：2018-06；2018 IEEE/CVF Conference on Computer Vision and Pattern Recognition

## 任务定位

研究任务：[CAD重建](/cad/tasks/reconstruction)。

由观测推断目标形状的CSG程序，按重建目的归类。

## 方法与贡献

- 把观测形状解析为构造实体几何程序，使用可组合基元及布尔操作描述形状。它展示了从像素或几何观测预测可执行构造过程的学习路线。CSG基元表达与完整工业特征历史是不同表示，不能直接等同。

## 技术要点

- **输入**：图像

- **表示**：CSG

- **方法**：程序综合

- **对象**：零件

- **要求**：几何
