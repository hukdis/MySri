# MUSE


## 论文信息

- **全名**：MUSE: Benchmarking Manufacturable, Functional, and Assemblable Text-to-CAD Generation
- **作者**：Xiaoyu Dong、Zhi Li、Xiao-Ming Wu
- **论文时间**：2026-05-27（arXiv首次提交）

## 任务定位

研究任务：共用基础。

功能、制造与装配要求的文本生成评价基准。

## 方法与贡献

- 面向复杂B-Rep装配，按代码、几何和设计意图三阶段评价生成质量，并用设计相关准则检查功能、制造和装配。它扩展只看单零件形状的文本到CAD评价。视觉裁判需在人类标注上验证，不能自动替代精确工程检查。

## 技术要点

- **输入**：文本

- **表示**：B-Rep

- **对象**：装配

- **要求**：制造 · 装配 · 物理功能
