# FEA反馈设计代理


## 论文信息

- **全名**：Self-Improving CAD Generation Agents with Finite Element Analysis as Feedback
- **作者**：Guijin Son、Jehyun Park、Seyeon Park、Sunghee Ahn、Youngjae Yu
- **论文时间**：2026-05-17（arXiv首次提交）

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

按工程需求迭代生成多零件设计，有限元提供反馈。

## 方法与贡献

- 用有限元分析和多视图反馈检查代理生成的多零件设计，并据工程需求进行迭代。它把反馈目标从几何相似推进到结构和功能行为。原文为进行中的工作，不能把初步结果当成成熟通用工程验证。

## 技术要点

- **输入**：文本 · 图像

- **表示**：CAD程序

- **方法**：代理 · 仿真反馈

- **对象**：装配

- **要求**：物理功能
