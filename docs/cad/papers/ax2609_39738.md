# CNCGEN


## 论文信息

- **全名**：CNCGEN: A Dataset and Framework for Machining Process Planning and Toolpath Generation from B-rep Models
- **作者**：Xiaolei Zhou、Boyi Lin、Yuchao Feng、Jianwei Zheng
- **论文时间**：2026-09-30（arXiv首次提交）

## 任务定位

研究任务：[CAD理解、评估与规划](/cad/tasks/analysis)。

主要输出三轴加工操作与路径，不把路径生成等同新零件设计。

## 方法与贡献

- 围绕持续制造对象和变化中的毛坯状态，联合生成加工操作及刀具路径，并提供对齐几何、过程和检验结果的数据。它把最终零件CAD进一步连接到材料去除过程。任务限定三轴加工，不能把它视为完整设计生成或任意工艺规划。

## 技术要点

- **输入**：CAD · 毛坯状态

- **表示**：加工过程

- **方法**：自回归

- **对象**：零件

- **要求**：制造
