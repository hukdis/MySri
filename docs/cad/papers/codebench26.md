# 3DCodeBench


## 论文信息

- **全名**：3DCodeBench: Benchmarking Agentic Procedural 3D Modeling Via Code
- **作者**：Gao, Yipeng、Shu, Lei、Ye, Genzhi、Xiong, Xi、Makadia, Ameesh、Guo, Meiqi、Itti, Laurent、Chen, Jindong
- **论文时间**：2026-05-31（arXiv首次提交）
- **正式发表记录**：2026；NeurIPS 2026

## 任务定位

研究任务：共用基础。

通用程序化三维建模邻接评价资源。

## 方法与贡献

- 评价代理把文本或图像变成可执行三维建模程序，并以人类偏好补充结果比较。它关注API错误、组件连通和多轮修订等执行问题。程序化三维建模的范围比机械参数化CAD更广，应作为邻接基准阅读。

## 技术要点

- **输入**：文本 · 图像

- **表示**：CAD程序

- **对象**：程序化三维

- **要求**：几何 · 可执行性
