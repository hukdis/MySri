# 3D-PreMise


## 论文信息

- **全名**：3D-PreMise: Can Large Language Models Generate 3D Shapes with Sharp Features and Parametric Control?
- **作者**：Zeqing Yuan、Haoxuan Lan、Qiang Zou、Junbo Zhao
- **论文时间**：2024-01-12（arXiv首次提交）

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

文本描述驱动参数化新设计。

## 方法与贡献

- 通过程序综合控制三维建模软件，研究文本驱动的尖锐特征和参数化形状生成，并建立相应数据。它也观察视觉界面中的自纠正能力。程序化工业形状是研究对象，不能与所有原生机械特征历史形式直接等同。

## 技术要点

- **输入**：文本

- **表示**：CAD程序

- **方法**：语言模型

- **对象**：零件

- **要求**：几何
