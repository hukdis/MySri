# OmniMech · 工业图纸与多任务评测


## 论文信息

- **全名**：OmniMech: All-in-one Multimodal Mechanical Benchmark for 3D Reconstruction
- **作者**：Lu, Taiting、Liu, Runze、Dong, Ziwei、Bei, Sisong、Zeng, Jingying、Wang, Mingjia、Li, Zhenghao、Lin, Kaiyuan、Wu, Yi-Shan、Zheng, Yangshoudu、Pan, Hongxing、Zhang, Kai、Shi, Guoliang、Ma, Ling、Yang, Yifan、Lu, Jiaying、He, Qi、Chen, Sung-Liang、Chen, Yi-Chao、Jin, Yincheng、Gowda, Mahanth

## 任务定位

研究任务：共用基础。

工业图纸与多任务工程评价资源。

## 方法与贡献

- 针对通用形状数据难以反映机械图纸精细结构与尺寸公差的问题，提出包含完整尺寸标注图纸和多种几何表示的工业机械评测。它覆盖图纸到可执行程序、二维到三维推理、标注理解与工具辅助验证四类任务，强调可执行性、尺寸与容差的区别。摘要写有未来公开承诺，本次未核实完整数据入口，因此保留为评测研究节点，不列为已经能直接下载的训练数据。

- **表示**：CAD程序 · B-Rep

- **对象**：零件
