# Img2CAD · Structured Visual Geometry


## 论文信息

- **全名**：Img2CAD: Conditioned 3D CAD Model Generation from Single Image with Structured Visual Geometry
- **作者**：Tianrun Chen、Chunan Yu、Yuanqi Hu、Jing Li、Tao Xu、Runlong Cao、Lanyun Zhu、Ying Zang、Yong Zhang、Zejian Li、Linyun Sun
- **论文时间**：2024-10-04（arXiv首次提交）
- **正式发表记录**：2025-11；IEEE Transactions on Industrial Informatics

## 任务定位

研究任务：[CAD重建](/cad/tasks/reconstruction)。

单图结构几何恢复为可编辑CAD，与另一篇Img2CAD分开。

## 方法与贡献

- 从单张图像生成带可编辑参数的CAD模型，以结构化视觉几何（SVG，向量化线框）作为中间表示，将视觉条件连接到CAD生成。它同时提出ABC-mono渲染数据与真实拍摄物体配对的KOCAD数据，补充图像条件CAD研究资源；这里的SVG不是直接等同于常见的SVG文件格式。这是2024年10月的同名独立论文，与7月的VLM辅助条件因子化Img2CAD分开记录；作者的首次主张不视为已核实优先权，效果和数据规模仍按原摘要范围理解。

## 技术要点

- **输入**：图像

- **表示**：CAD程序

- **方法**：视觉语言模型

- **对象**：零件

- **要求**：几何 · 可编辑性
