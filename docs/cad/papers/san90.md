# Assembly Sequence Planning


## 论文信息

- **全名**：Assembly Sequence Planning
- **作者**：Arthur C. Sanderson、Luiz S. Homem de Mello、Hui Zhang
- **论文时间**：1990-03-15（正式/机构年份记录）
- **正式发表记录**：1990-03-15；AI Magazine 11(1)

## 任务定位

研究任务：共用基础。

装配顺序规划的历史基础。

## 方法与贡献

- 从零件几何、装配构型及中间装配稳定性推理可行的配合顺序，并讨论显式和隐式计划表示。它把装配看成受几何与机械条件限制的过程。此处作为规划问题的早期基础，不推断现代神经装配网络直接继承其算法。
