# CIT-CAD


## 论文信息

- **全名**：CIT-CAD: Constraint Intent Tree-based CAD Code Generation and Verification
- **作者**：Yali Du、Hui Sun、San-Zhuo Xi、Ming Li
- **论文时间**：2026-09-07（arXiv首次提交）

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

从需求意图树生成程序并核验；验证为明确次用途。

其他任务：[CAD理解、评估与规划](/cad/tasks/analysis)

## 方法与贡献

- 从文本推断实体、层次、布尔角色和关系组成的约束意图树，再用它指导代码生成和检查。它让设计意图成为可定位违反项的结构化对象。若意图树提取错误或检测器覆盖不足，验证结果本身也会偏离用户要求。

## 技术要点

- **输入**：文本

- **表示**：CAD程序 · 约束图

- **方法**：语言模型 · 执行反馈

- **对象**：零件

- **要求**：约束 · 规格验证
