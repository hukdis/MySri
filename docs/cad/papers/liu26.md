# CAD-Factory


## 论文信息

- **全名**：Multi-Agent CAD Code Generation
- **作者**：Yang Liu、Daxuan Ren、Yijie Ding、Jianmin Zheng、Fang Deng
- **论文时间**：2026-07-19（正式/机构年份记录）
- **正式发表记录**：2026-07-19；Proceedings of the Special Interest Group on Computer Graphics and Interactive Techniques Conference Conference Papers

## 任务定位

研究任务：[CAD生成](/cad/tasks/generation)。

分解程序结构与参数实例化完成文本新设计。

## 方法与贡献

- 以结构化程序综合组织文本到CAD，分离程序层次和参数实例化，并由规划、编程和评审模块协作。它将CAD结构和参数语义纳入生成与视觉修订。本文的方法名与论文标题不同，具体设计优劣需按同等任务和预算比较。

## 技术要点

- **输入**：文本

- **表示**：CAD程序

- **方法**：代理 · 程序综合 · 执行反馈

- **对象**：零件

- **要求**：尺寸 · 几何
