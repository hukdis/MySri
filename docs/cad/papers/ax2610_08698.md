# PrimitiveCAD


## 论文信息

- **全名**：PrimitiveCAD: An LLM-Based Point-to-CAD Reconstruction with Primitive-Aware Tokenization and Operation Alignment
- **作者**：Jian Gao、Kailin Bi、Jiamin Xu、Jinlan Xu、Gang Xu
- **论文时间**：2026-10-06（arXiv首次提交）

## 任务定位

研究任务：[CAD重建](/cad/tasks/reconstruction)。

点云观测到CAD基元和操作恢复。

## 方法与贡献

- 针对点云到CAD中图元结构容易丢失的问题，采用图元感知词元化、操作对齐损失和特征线奖励。它把LLM训练信号从一般token预测推进到CAD基元和操作。当前预印本中的优势应在相同输入、数据和预算下复核。
